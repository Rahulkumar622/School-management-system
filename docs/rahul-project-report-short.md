## Introduction

School Management System is a web-based application developed to manage important school activities in a simple and organized way. The system helps in maintaining student records, teacher details, attendance, marks, fee information, notifications, and basic administration work. It reduces manual paperwork and improves the speed and accuracy of daily school operations.

## Objective

The main objective of this project is to digitalize the basic management work of a school. The system aims to:

- store student and teacher records in one place,
- manage attendance and marks,
- handle fee-related information,
- provide separate access for admin, teacher, student, and parent,
- improve communication and reporting.

## Problem Definition

In many schools, records are maintained manually, which takes more time and can lead to errors, duplication, and difficulty in searching data. A computerized system is needed to manage school information efficiently and securely.

## Tools and Technologies Used

- Frontend: React
- Backend: Node.js and Express.js
- Database: MySQL
- Charts and Reports: Chart.js
- Platform: Web Browser

## Modules of the System

The major modules of the School Management System are:

- Admin module for managing school data,
- Teacher module for attendance and marks entry,
- Student module for viewing academic details,
- Parent module for monitoring student information,
- Fee and report module for financial and academic reports,
- Notification module for important updates.
